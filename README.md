# チェキ整え

チェキのフィルムを撮った写真から、フィルムの部分だけをまっすぐ切り出して整えるアプリ。

## 使う

### ブラウザで使う

<https://cheki-totonoe.vercel.app/> を開く。スマホでもパソコンでも使える。

### Android アプリで使う

[Releases](https://github.com/chibik1/cheki-totonoe/releases/latest) から最新の `ChekiTotonoe-[version].apk` をダウンロードしてインストールする。

- Android 7.0 以降
- 初めてのときは「提供元不明のアプリ」のインストールを許可する
- 新しい版は、そのまま上書きインストールできる
- 使うときはインターネットにつながっている必要がある
- Chrome が入っていると、アドレスバーのない全画面で開く。Chrome がない端末でもアプリの中で開ける

## 撮り方のコツ

- 暗めの机や布の上に置いて、フィルム全体が入るように撮る
- 読み込める写真は JPEG・PNG・WebP (HEIC は選べない)
