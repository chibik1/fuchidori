# ふちどり

撮影したチェキのリタッチアプリ。
カメラで取り込み(撮影済みの画像からでも可)、フィルムのサイズに合わせて自動でトリミング。
自動顔認識によりモザイク・塗りつぶし・スタンプでプライバシー保護。
テキスト追加機能：名前(グループ名)、通算撮影枚数、初めて撮影した日からの日数計算。

写真はスマホやパソコンの中だけで処理する。どこかに送られることはない。

## はじめかた

### ブラウザで使う

<https://fuchidori.vercel.app/> を開く。スマホでもパソコンでも使える。

### Android アプリで使う

[Releases](https://github.com/chibik1/fuchidori/releases/latest) から最新の `Fuchidori-[version].apk` をダウンロードしてインストールする。

- Android 7.0 以降
- 初めてのときは「提供元不明のアプリ」のインストールを許可する
- 新しい版は、そのまま上書きインストールできる
- Chrome が入っていると、アドレスバーのない全画面で開く。Chrome がない端末でもアプリの中で開ける

## 使い方

画面の 1〜5 の順に進める。下のボタンで前の手順にも戻れる。

### 1. 写真を読み込む

「カメラで撮る」か「写真を選ぶ」を押す。パソコンでは、写真を画面にドラッグしてもよい。

- 暗めの机や布の上に置いて、フィルム全体が入るように撮るときれいに仕上がる
- 読み込める写真は JPEG・PNG・WebP など (HEIC は選べない)

### 2. ふちを合わせる

フィルムの種類 (mini / SQUARE / WIDE / 比率自由) を選び、黄色い点をドラッグしてフィルムの四隅に合わせる。

| ボタン | できること |
|---|---|
| 自動検出 | フィルムの位置を自動で探す |
| フチに吸着 | 点をフィルムのふちにぴったり寄せる |
| 上下入替 | 上下が逆になったときに入れ替える |

### 3. 色と明るさを整える

プレビューを押している間は、補正前の写真が見られる。

| タブ | できること |
|---|---|
| 自動 | 色かぶりを取る、明暗の幅を整える、90° 回転、補正のリセット |
| 明るさ | 明るさ、コントラスト、シャープ |
| 色 | 鮮やかさ、青 ↔ 黄、緑 ↔ 赤紫 |
| プリセット | 色の設定に名前を付けて保存し、次から呼び出す |

### 4. 画像処理 (顔を隠す)

SNS に載せるときなどに、顔を隠せる。使わないときは、そのまま「装飾へ」を押す。

- 隠し方は モザイク / 塗りつぶし / スタンプ から選ぶ
- 「顔を検出」で顔を自動で探す
- 空いている所をタップすると枠を追加、枠をドラッグで移動、右下の角で大きさを変更
- いらない枠は「選択を削除」、全部消すなら「すべて消す」

### 5. 装飾する

| タブ | できること |
|---|---|
| 切り抜き | フチごと / フチを白く / 写真だけ から仕上がりを選ぶ |
| 余白・背景 | 周りに余白を付ける。背景は 単色・グラデーション・柄 から選ぶ |
| 文字 | 名前とグループ名、通算枚数、出会ってからの日数を入れる。書体・大きさ・色も変えられる |

通算枚数は、保存すると次の写真の分が自動で 1 枚増える。

### 保存する

「保存」を押すと仕上がりの画像が出るので、長押し (パソコンでは右クリック) して保存する。
続けて次の写真を整えるときは「新しく読み込む」を押す。

## ネットがないとき

一度開いたことがあれば、電波のない場所でも起動して使える。

- 最初の 1 回は、ネットにつながった状態で開く
- ネットがある間に使った書体は保存される。まだ使っていない書体や文字は、スマホ標準の書体で表示される
- 新しい版は、次にネットにつながったときに自動で反映される
